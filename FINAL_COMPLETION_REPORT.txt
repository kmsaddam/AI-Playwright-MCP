================================================================================
                         TEST EXECUTION GUIDE
================================================================================

QUICK START:

1. Install Dependencies
   $ npm install

2. Run All Tests
   $ npm test

3. View Results
   $ npx playwright show-report

4. Run Specific Test
   $ npx playwright test api-booking.spec.ts -g "POST"

5. Debug Mode
   $ npx playwright test --debug

ADVANCED OPTIONS:

Run with UI Mode (Interactive):
  $ npx playwright test api-booking.spec.ts --ui

Run with Headed Browser (See actions):
  $ npx playwright test search-computer.spec.ts --headed

Generate JSON Report:
  $ npx playwright test --reporter=json

Generate Markdown Report:
  $ npx playwright test --reporter=markdown

Run Specific Test File:
  $ npm test api-booking.spec.ts
  $ npm test search-computer.spec.ts

List All Tests:
  $ npx playwright test --list
